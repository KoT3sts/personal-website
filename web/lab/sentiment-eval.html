Sentiment, measured

Two sentiment models on 3,000 public review sentences: where each one fails, and what a threshold costs.

This is a public reproduction on open data, built to show how I evaluate a classifier. It is not the Companionship Chatbot’s model, data or reported result.

Where they fail

Picked by rule, not by hand: the most confident shared errors, then negation cases, then errors only one model makes.

Double negatives beat both models: “wasn’t terrible” and “not a bad watch” read as negative, because “terrible” and “bad” are among the strongest negative words in training and the not_ feature has too few examples to flip them. Model A counts every token, so nine exclamation marks in “no longer working!!!!!!!!!” are nine votes for positive; model B only notes that “!” is present and gets it right. Model A also learned that “Hitchcock” signals a positive review.

Method

  • Data. 3,000 labelled sentences, 1,000 each from Amazon, Yelp and IMDb, half positive. 21 exact repeats (ignoring case and spacing) were dropped first, leaving 2,979, so no sentence can appear in both training and test.
  • Split. Seeded (331) and stratified by source and label: 2,084 train, 299 validation, 596 test.
  • Features. Lowercase regex tokens; contractions split so “don’t” keeps its “n’t”. Model A counts unigrams. Model B uses unigram and bigram presence plus a not_ copy of each word between a negation and the next punctuation mark.
  • Training. A: multinomial Naive Bayes, Laplace smoothing (alpha 1), not tuned. B: L2 logistic regression, full-batch gradient descent with Nesterov momentum, 1,000 steps; the L2 strength (3 × 10−5) was picked from 7 values by validation log loss. The test set played no part in fitting or tuning.
  • Uncertainty. 1,000 bootstrap resamples of the test set; intervals are the 2.5th to 97.5th percentiles. F1 for A: 0.757 to 0.828; B: 0.764 to 0.835; B minus A: −0.021 to +0.038 (B ahead in 70% of resamples).

Limits

  • Small sample. Each source contributes about 200 test sentences, so a slice accuracy moves by half a point with every sentence. Read slice gaps as hints, not findings.
  • One split, one seed. The bootstrap covers test-set sampling only. A different split or seed would also move the numbers.
  • Easier than real use. The dataset’s authors kept sentences with a clear polarity and no neutral ones. Chat messages, sarcasm and mixed feelings are harder, and these models have never seen them.
  • Domain shift is not tested. Training and test sentences come from the same three sites. Training on two sources and testing on the third would be the next experiment.
  • Examples are quoted, not written. The failure examples are verbatim test sentences from the public dataset, reviews posted on Amazon, Yelp and IMDb; any names in them come from that text.
  • Scores are not calibrated. Neither model’s P(positive) was checked against observed frequencies. Naive Bayes pushes more of its scores to the extremes, so the same slider move changes fewer of its calls.

Reproduce it

One script, Python 3 standard library only. It downloads the zip (or reuses a cached copy outside the repository), checks its SHA-256, trains both models and writes the predictions this page reads.

python3 scripts/eval/build_sentiment_eval.py

The same seed gives a byte-identical file. Only test sentences and their predictions are published, as sentiment-eval.json.

Data: Kotzias, D., Denil, M., de Freitas, N., and Smyth, P. “From Group to Individual Labels Using Deep Features.” KDD 2015. Sentiment Labelled Sentences, UCI Machine Learning Repository, doi:10.24432/C57604, licensed CC BY 4.0. Changes: exact repeats removed, punctuation encoding repaired.
